RESUME PLACEHOLDER

To add your resume:

1. Create your resume in PDF format
2. Name it: resume.pdf (or Priyanshu_Garg_DevOps_Resume.pdf)
3. Place it in the public/ directory

The download link will work automatically once the file is in place.

Users can download it by clicking the "Download Resume" button on:
- Hero section
- Skills section  
- Contact section

File path: /public/resume.pdf
